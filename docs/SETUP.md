# 教學手冊 · 從零到能用

這份手冊帶你把整套系統架起來。全程不用寫程式,但你要會跟 Claude 對話。

預計時間:**15 到 20 分鐘**。

---

## 你需要什麼

| 必要 | 說明 |
|---|---|
| Claude 帳號 | 需要能用 **Cowork 模式**(桌面 app 或 claude.ai)。Skill 與 Artifact 都是這個模式的功能。 |
| 一個瀏覽器 | Safari、Chrome、Edge 都行。發音功能用的是瀏覽器內建語音,不需要安裝任何東西。 |

| 選用 | 用來做什麼 |
|---|---|
| Claude 桌面 app + 連結資料夾 | 才能把備份檔寫進你電腦的資料夾。只用雲端的話可以跳過。 |
| iCloud / Google Drive | 讓 iPhone、iPad 讀得到備份的 PDF。 |

---

## 第一步:建立單字家教 Skill

Skill 決定了解析的格式與口吻,是整套系統的核心。

1. 打開 `skill/toeic-vocab-tutor/SKILL.md`,**整份複製**。
2. 在 Claude 裡對它說:

   > 幫我建立一個 skill,內容我貼在下面:
   >
   > (貼上剛剛複製的內容)

3. Claude 會跳出一張審核卡,按儲存。

**先別急著測試**,裡面有個網址還是佔位符,第三步會填。

---

## 第二步:發布單字發音板

發音板是一個網頁,但它不是靜態的:它有自己的雲端資料庫(存單字),而且能自己向 Claude 提問(生成解析)。這兩件事要在發布時宣告。

1. 打開 `artifact/pronounce.html`,**整份複製**。
2. 對 Claude 說:

   > 幫我把下面這份 HTML 發布成 Artifact,
   > capabilities 要 `{"db": {}, "sample": {}}`,
   > 標題「單字發音板」。
   >
   > (貼上 HTML)

3. 發布完成後,**把網址記下來**,長得像:
   `https://claude.ai/code/artifact/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

> **`db` 和 `sample` 是什麼?**
> `db` 讓頁面有一個雲端資料庫,單字存在那裡,所以你換裝置打開看到的是同一份。
> `sample` 讓頁面可以直接問 Claude 問題 —— 這就是「在輸入框打字就自動生出解析」的原理。
> 兩個都是 Claude 平台原生的能力,不需要你自己架伺服器,也沒有 API key 要管。

---

## 第三步:把兩邊接起來

回到你剛才存的 Skill,把裡面的 `PASTE_YOUR_ARTIFACT_URL_HERE` 換成第二步拿到的網址。

對 Claude 說:

> 幫我更新 toeic-vocab-tutor 這個 skill,把 PASTE_YOUR_ARTIFACT_URL_HERE 換成
> https://claude.ai/code/artifact/(你的網址)

接好之後,你在對話框查的每個字都會自動進發音板。

---

## 第四步:測試

在 Claude 對話框直接打一個英文單字,什麼指令都不用加:

```
comply
```

應該會發生兩件事:

1. Claude 回你一張完整的單字卡。
2. 回覆最後一行說「已經加進發音板了」。

打開發音板,你會看到 `comply` 出現在今天的日期底下,點下去可以聽發音、看解析。

接著測試另一個入口:在發音板的輸入框打 `feasible`,按「加入今天」。字會馬上出現並唸出來,幾秒後解析自己填好。

> **第一次用 `sample` 時,頁面會問你要不要授權。** 按同意才會生成解析。這個呼叫算在你自己的 Claude 額度裡。

## 第五步(選用):設定自動備份

備份會把整個單字庫輸出成:

```
你的備份資料夾/
├── 2026-01-06/
│   ├── 2026-01-06.md
│   └── 2026-01-06.pdf
├── 2026-01-07/
│   ├── 2026-01-07.md
│   └── 2026-01-07.pdf
├── _全部單字.md
├── _全部單字.pdf
└── _tools/
    └── build_vocab.py
```

### 5-1 先手動跑一次

1. 在 Claude 桌面 app 裡連結一個資料夾當備份位置。
2. 把 `scripts/build_vocab.py` 放進那個資料夾的 `_tools/` 子資料夾。
3. 對 Claude 說:

   > 請把我的單字發音板(網址:…)的單字庫匯出,
   > 用 `_tools/build_vocab.py` 產生 MD 與 PDF,寫回這個資料夾。

### 5-2 設成每天自動跑

打開 `automation/daily-backup-task.md`,照裡面的說明請 Claude 建立排程任務。記得把檔案裡的**網址與資料夾路徑**換成你自己的。

> **排程跑的時候你的電腦要是醒著的。** 筆電闔上或睡著就會跳過那一次。如果常錯過,把時間改到你確定在用電腦的時段,例如晚上十點。

## 第六步(選用):手機與平板

單字庫本來就在雲端,不在你電腦裡,所以手機平板不用做任何同步設定:

1. 用手機或平板的瀏覽器打開發音板網址(要登入同一個 Claude 帳號)。
2. iOS:按分享 →「加入主畫面」。它會變成一個獨立圖示,開起來沒有網址列,跟原生 app 一樣。

iOS 內建的 Samantha(美)、Daniel(英)語音品質比多數桌面瀏覽器好。

**備份檔要在平板上看**,就把備份資料夾設在 iCloud 雲端硬碟或 Google Drive 底下。PDF 在「檔案」app 長按分享 → Notability,就能手寫劃重點。

## 常見問題

**沒有聲音?**
檢查裝置沒有靜音、瀏覽器分頁沒被靜音。發音板右上角的語音下拉選單若是空的,代表系統還沒載入語音,重新整理一次通常就好。Safari、Chrome、Edge 都支援;部分 Linux 環境沒有內建語音。

**貼了單字,Claude 沒有出卡片,而是普通回答?**
Skill 沒被觸發。試著說「用單字家教解釋 comply」,或檢查 Skill 是否已啟用。

**發音板打字沒有生成解析?**
先確認發布時有帶 `sample` capability。可以點開那個字,視窗裡會有「生成解析」按鈕手動重試。

**單字存進去了,但解析是空的?**
生成失敗(通常是網路或額度)。點開那個字按「生成解析」重試即可。

**手機上看不到電腦加的字?**
確認兩邊登入同一個 Claude 帳號,而且開的是同一個 Artifact 網址。

**「依序播放」在 iPhone 上播到一半停了?**
iOS 對連續語音有限制。發音板已經用「一次把整批排進佇列」的做法繞開,若仍中斷,按停止再重播。

**PDF 裡的中文變成方框?**
產生 PDF 的環境缺中文字型。`build_vocab.py` 需要 Noto Sans CJK,在 Claude 的雲端環境是內建的。
